# Interior Demo — Updated Plan + Flaw Fixes

## What I found (root cause of your Phase 1 blocker)

**The door is never clickable.** In `components/DoorEntry.tsx:80-83`, the white "Entering the House…" overlay is `absolute inset-0`, sits **after** the door scene in DOM order, and has no `pointer-events-none`. Even at `opacity-0` it still hit-tests and paints on top — it swallows every click, so the door's `onClick` never fires. This is why "click event needs verification."

Other confirmed flaws (all verified in code):
1. **No 3D perspective** — no ancestor sets `perspective`, so `rotateY(-95deg)` squashes flat instead of swinging.
2. **AudioContext leak** — a new context per knock, never closed; Chrome caps ~6, so knocks go silent after repeat clicks.
3. **Uncleaned timers** — three `setTimeout`s in the click handler; will crash-on-unmount once navigation exists.
4. **"knocking" phase is visually dead** — no animation, just caption text.
5. **No keyboard access** — plain `<div onClick>`; keyboard users can't enter (README Phase 4 item, trivial to pull forward).
6. **Off-brand styling** — hardcoded stone/amber instead of your brand tokens in `globals.css`.

Plus: the whole July landing page (Navbar, Hero, HeroScene, Portfolio, Services, Contact, Booking, DesignBrief, Footer, `lib/data.ts`) is complete but orphaned — ideal raw material for Phase 3 routes.

Decisions made (defaults since questions weren't answered — veto any at approval): build **Phases 1–3 end-to-end**, hub as **procedural R3F rooms** (no external assets needed), DesignBrief **folded into /contact** as the consultation form.

## Part 1 — Fix Phase 1 (`components/DoorEntry.tsx`)

1. **Click fix:** add `pointer-events-none` to the transition overlay (it's purely visual).
2. **Real 3D swing:** wrap the door in a `perspective: 1200px` container.
3. **Audio:** one module-level singleton `AudioContext`, created lazily inside the click (user-gesture safe), `resume()` if suspended; no more per-knock contexts.
4. **Timer cleanup:** keep timeout IDs in refs, clear on unmount via `useEffect`.
5. **Knock animation:** add a small CSS `@keyframes knock` thump (scale/translate) applied during the knocking phase, so the phase is visible.
6. **A11y + skip:** door becomes a `<button>` (Enter/Space work), plus a visible "Skip intro →" that routes straight to `/house`.
7. **Navigation:** at the `transitioning` phase, `router.push("/house")` — no more dead-end overlay.
8. **Return-visit skip:** `sessionStorage.doorSeen`; on repeat visits within the session, `/` jumps straight to `/house`.
9. **Brand tokens:** swap stone/amber hardcodes for `bg-background`, `text-accent`, `font-display`, etc.
